# Архитектуры фронтенда и мини-проект

В этом курсе мы используем **Vite + React 19 + TypeScript** и **React Router v7**. Ниже — краткая выжимка по популярным подходам.

## Подходы к архитектуре
1. **Feature-Sliced Design (FSD)**  
   Идея: делим код на слои (`app/`, `processes/`, `pages/`, `widgets/`, `features/`, `entities/`, `shared/`) и горизонтальные сечения по **фичам**.  
   Когда уместно: средние/крупные проекты с независимыми фичами, постепенной разработкой и переиспользованием.

2. **Atomic Design**  
   Уровни: `atoms → molecules → organisms → templates → pages`.  
   Когда уместно: дизайн-системы, сильный упор на UI-композицию.

3. **Module/Domain-Oriented**  
   Идея: группировать код по доменным областям (модулям), внутри которых хранить UI, логику, сервисы.  
   Когда уместно: когда доменные границы очевидны и стабильны.

## Мини-проект «Task Board»
- **Фичи**: создать задачу, изменить статус, фильтровать по тегам.
- **Страницы**: `/`, `/tasks/:id`, `/about`.
- **REST**: `GET/POST/PATCH/DELETE /api/tasks` (моки или реальный backend).
- **Роутинг**: Nested Routes для вложенных табов на странице задачи.
- **Стили**: CSS Modules + `clsx`.
- **Тесты**: `vitest + @testing-library/react`.

См. задания в `useState/`, `useEffect/`, `useRef/`, `props/` — они шаг за шагом подводят к реализации мини-проекта.
