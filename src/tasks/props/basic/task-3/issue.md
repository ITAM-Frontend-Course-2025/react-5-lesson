# Props basics #3

**Цель:** Придумать и типизировать пропсы компонента и корректно их использовать.

## Задание
Создайте компонент `UserCard` (name: string, age?: number). Выведите имя и возраст, если передан.


### Ловушки
- Не забывайте про optional пропсы
- Выведите условно поле age


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
