# useRef node #2

**Цель:** Получить доступ к DOM-элементу через ref и сфокусировать input по кнопке.

## Задание
По клику на кнопку вызывайте inputRef.current?.focus().


### Ловушки
- Проверьте тип `HTMLInputElement`
- Проверьте null-совместимость


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
