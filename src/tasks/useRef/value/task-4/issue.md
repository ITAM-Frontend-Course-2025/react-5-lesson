# useRef value #4

**Цель:** Хранить изменяемое значение между рендерами, не вызывая перерендер.

## Задание
Счётчик кликов храните в ref, а не в state. Отображайте значение по кнопке «Show».


### Ловушки
- ref.current не вызывает перерендер
- state вызывает перерендер


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
