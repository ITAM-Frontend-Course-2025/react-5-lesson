# useEffect standard #4

**Цель:** Выполнить эффект однократно при маунте.

## Задание
Добавьте эффект без зависимостей, который пишет в консоль 'mounted'.


### Ловушки
- Не вызывайте setState внутри без условий.
- Не забывайте [] зависимостей.


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
