# Object merge trap

**Цель:** Практика управления локальным состоянием.

## Задание
Измените только одно поле объекта в state, не теряя другие поля.


### Ловушки
- Следите за batching
- Не мутируйте state напрямую


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
