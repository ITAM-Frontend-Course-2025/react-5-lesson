# Counter x2 trap

**Цель:** Практика управления локальным состоянием.

## Задание
Сделайте счётчик и кнопку '+2'. Нельзя вызывать setCount(count+1) дважды подряд — используйте функциональный сеттер.


### Ловушки
- Следите за batching
- Не мутируйте state напрямую


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
