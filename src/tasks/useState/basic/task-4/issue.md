# Derived state antipattern

**Цель:** Практика управления локальным состоянием.

## Задание
Не храните производное значение в state — вычисляйте на лету.


### Ловушки
- Следите за batching
- Не мутируйте state напрямую


### Критерии приёмки
- Все тесты проходят.
- Компонент не падает по типам (TS).
- Поведение соответствует описанию.
